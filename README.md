Система бронирования кабинетов
Простое и эффективное API на базе FastAPI, предназначенное для управления бронированием помещений. Проект позволяет добавлять новые записи с проверкой на пересечение времени и удалять существующие бронирования.

Основные возможности
Добавление бронирования: Создание записи с указанием названия кабинета, времени начала и окончания.

Автоматическая проверка занятости: Система не позволит забронировать кабинет, если на это время уже есть активная бронь.

Удаление бронирований: Возможность отменить запись по её ID.

Автоматическое создание базы данных: При запуске приложение самостоятельно создает таблицу в SQLite, если она отсутствует.

Технологический стек
Язык: Python

Фреймворк: FastAPI

ORM: SQLAlchemy

База данных: SQLite

Структура базы данных
В таблице bookings хранятся следующие данные:  

id: Уникальный номер брони.

room: Название или номер кабинета.

start_time: Дата и время начала.

end_time: Дата и время окончания.
